# werewolf

Werewolf against seven villagers whose suspicions are real numbers.

Every message you send is measured by a System One model (TypeSafe Jev) in one request: does it contradict what you said before, does it dodge the question, does it accuse with evidence. Each villager keeps a probability over who the wolves are and updates it within a fraction of a second. They speak from authored lines, never generated text. You win by being persuasive to people whose trust is a number you can see.
